# Changelog

All notable changes are documented here. This project follows Semantic Versioning for its local CLI, Skills index, and plugin metadata.

## 0.2.0 — Unreleased internal preview

- Added six modular QFPay integration Skills and a compatibility router.
- Added a Sandbox-first local CLI, Node hosted-checkout/MPM templates, callback idempotency helpers, and a read-only local stdio MCP.
- Added contract, skill, pay-type, evaluation, and package-integrity release checks.
- Kept Remote MCP, credential brokerage, merchant/store scope, payment execution, and Production approval workflows out of scope.
